# 05 · 行动手册（个人主体 / 无服务器 / 云托管路线）

> 这份是**给你这一种情况**的单一入口：未成年参赛、家长做主体、没有服务器也没有备案域名、
> 后端跑微信云托管。其他文档是参考手册（[10 云托管](10-deploy-cloudrun.md)、
> [20 自有服务器](20-deploy-selfhosted.md)、[30 发布](30-release-miniprogram.md)、
> [40 排错](40-troubleshooting.md)、[00 竞赛清单](00-competition-checklist.md)），
> 遇到具体问题时再去翻。
>
> 起点时间：**2026-09-25**；终点：**2026-10-17 前作品必须已正式上线**。共 22 天。

## 0. 你的三个前置事实（决定了后面每一步）

| 事实 | 后果 |
| --- | --- |
| 你**未满 18 岁** | 个人主体小程序要求「18 岁以上有国内身份信息的微信实名用户」（官方原文）。**主体与管理员都必须是家长本人**，你做**项目成员** |
| **没有服务器、没有域名** | 走云托管 Track A：免域名、免证书、免**域名备案**；小程序用 `wx.cloud.callContainer` 直连 |
| **小程序备案免不掉** | 2023-09 起新注册小程序须完成备案才能上架。它和"域名备案"是两回事，任何路线都要做 |

**一句话记住这三条边界**：主体是家长的、代码是你的、备案是必须的。

## 阶段 A · 账号（今天，约 30 分钟）

### A1 主体与管理员，必须是同一位家长

- [ ] 用**家长的**身份证姓名 + 身份证号 + **家长本人手机号**填「主体信息登记」
- [ ] 「管理员身份验证」用**家长本人的微信**扫码（该微信必须已完成实名/绑卡）
- [ ] 三样一致：**主体身份证 = 管理员手机号 = 管理员微信，都是同一位家长**
- [ ] 注册邮箱也建议用家长的（只是登录名，但以后找回账号时省事）

> ⚠️ **不要用同学、朋友或任何"其他人的号"**。管理员微信 = 这个小程序的最高权限：能改密码、
> 能找回账号、能提交审核、能点发布。绑给别人等于把作品交出去，而且个人主体**不可变更主体**。
> 也**不要买账号或借身份证**——随时会被原主体找回，且违规。

### A2 补手机号（如果报 `-601009`）

症状：开通云托管时报 `该小程序没有绑定手机号`。见 [40 排错 0.1](40-troubleshooting.md#01-云托管开不了-601009-该小程序没有绑定手机号)。

- [ ] 公众平台 → **成员管理**（旧版叫「成员设置」）→ **管理员**那一行 → **修改** → 补手机号
- [ ] 找不到就试「设置 → 基本设置 → 账号信息」或「管理 → 成员管理」

### A3 小程序基本信息（名称 / 头像 / 简介）

**名称 —— 避开教育行业词，否则会被要求出示《商标注册证》或教育资质**（实测：`理想中的班级`
直接被判「可能涉及特定行业领域」）。

| 不要出现在名称里 | 安全候选（按顺序试，系统实时查重） |
| --- | --- |
| 班级、课堂、教学、学校、学生、老师、作业、课程、教育、培训、辅导、考试、成绩、试卷 | **积分小芽** ／ 小芽积分 ／ 绿芽积分 ／ 成长积分助手 ／ 积分口袋 |

- [ ] 名称：`______`（避开上表左列；名称修改次数很有限，别拿雷词反复试）
- [ ] 头像：用 [docs/wechat/assets/miniprogram-avatar-1024.png](assets/miniprogram-avatar-1024.png)
      （同目录有 144×144 的小图），是仓库自己的品牌图形，不涉版权
- [ ] 简介：**记录积分、兑换奖励的小工具**（同样不要出现班级/学生/老师/作业/在线教学）

### A4 服务类目

- [ ] 选 **「工具」** 下的子类（以控制台实际可选列表为准），主营类目与功能对齐
- [ ] 选完确认后台提示的**资质要求为空** —— 你是个人主体，教育类基本对个人关闭
- [ ] 口径一致：**名称像工具、类目是工具、简介是工具**，审核最顺

### A5 把你加成开发者

- [ ] 家长在「用户身份 → **成员管理** → 添加成员」里，用**你的微信号**加为**项目成员**
      （个人主体最多 15 个项目成员）；不然后面你无法用开发者工具上传代码

### A6 拿到这两样（放好，别外传）

- [ ] **AppID**：左下角账号名（`gh_…`）→ **账号设置** → AppID（`wx` 开头那串）
- [ ] **AppSecret**：「开发与服务 → 开发管理 → 开发设置」→ 生成/查看
      **只填进云托管的环境变量**，不要贴聊天、不要进仓库、不要写进任何文档

## 阶段 B · 小程序备案（**今天提交，这是最长的一条**）

- [ ] 后台首页「**小程序备案 未备案**」那一行 → 提交备案（需先完成 A3/A4）
- [ ] 材料（个人主体）：家长身份证正反面、手机号、邮箱；小程序名称、服务类目、简介；可能要人脸核验
- [ ] 流程：平台初审 1–3 个工作日 → 省通信管理局审核 → **管局短信核验**
- [ ] ⚠️ **核验短信通常 24 小时内必须点链接确认**，发给**备案负责人本人（家长）的手机**；
      漏了要退回重来，一来一回一周。**叮嘱家长：手机别静音，短信当天处理**
- [ ] 通过后拿备案号。预期：1–3 周，个人主体没有捷径

> 备案期间不用干等：阶段 C、D 全部可以并行。

## 阶段 C · 代码与本地联调（可与 A、B 并行）

- [ ] 推分支到 GitHub（云托管要从仓库拉代码）：
      `git push -u origin feat/wechat-miniprogram`
- [ ] 装**微信开发者工具**（[下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)）
- [ ] 导入项目：目录选仓库里的 **`miniprogram/`**（不是仓库根）
- [ ] 本地联调需要后端在跑：
      - 本机起 API：`npm run start`（3001 端口）
      - 服务端 `.env` 加 `WECHAT_ALLOW_DEV_LOGIN=1`，客户端 `miniprogram/config/index.ts` 里
        `DEV_LOGIN_OPENID` 填任意字符串（如 `dev-openid-alice`）
      - 开发者工具「详情 → 本地设置」勾上**不校验合法域名**（否则 `http://localhost` 会被拒）
- [ ] 真机预览前，先在工具里把「登录 → 绑定账号 → 作业 → AI 智学 → 教师加分」走一遍

> 类型检查用 `npx tsc --noEmit -p miniprogram/tsconfig.json`（不带 `--noEmit` 会往源码旁吐 `.js`）。

## 阶段 D · 云托管部署（备案的同时就能做完）

### D1 开通与建环境

- [ ] 用**家长（管理员）的微信**扫码登录 <https://cloud.weixin.qq.com/>
- [ ] 「自定义部署」→ 环境名称 `prod`（或 `think-class`）→ 网络类型 **系统创建** → 勾选条款 → 确定
- [ ] 记下**环境 ID**（形如 `prod-xxxxxxxx`）
- [ ] 那 10 张「免费快速部署」的模版卡片（Express/Koa/Django…）**是示例项目，全部忽略**

### D2 新建服务 → 绑定 GitHub 仓库

| 字段 | 填什么 |
| --- | --- |
| 代码来源 | **绑定 Github 仓库**（不要选"手动上传代码包"：官方上限 2 MiB，本仓库实测 **86.86 MiB**） |
| **DockerFile 文件** | **`deploy/Dockerfile`**（我们的 Dockerfile 不在根目录，必须显式指定） |
| 目标目录 | **留空**（构建上下文必须是仓库根） |
| 容器端口 | **3001** |
| 最大副本数 | **1**（硬要求：SQLite 只有一个写者） |
| 最小副本数 | 1（不冷启动；免费额度够本项目 22 天常开）。预算紧可设 0 |
| 健康检查 | HTTP `GET /api/health` |

### D3 环境变量（一次性填齐）

```text
ENCRYPTION_KEY=<32 位，你自己生成并离线备份>
SUPERADMIN_USERNAME=<自定>
SUPERADMIN_PASSWORD=<自定强密码>
WECHAT_APPID=<阶段 A6 拿到的 wx…>
WECHAT_SECRET=<阶段 A6 拿到的 AppSecret，只填这里>
DATABASE_FILE=/data/database.sqlite
DATABASE_SKIP_WAL=1
UPLOADS_DIR=/data/uploads
NODE_ENV=production
```

- [ ] `ENCRYPTION_KEY` 生成：`node -e "process.stdout.write(require('node:crypto').randomBytes(16).toString('hex'))"`
      **丢了这个，已加密的学生姓名永久不可读**；也要备份 `.env`/这份变量
- [ ] 生产环境**不要**设 `WECHAT_ALLOW_DEV_LOGIN`

### D4 挂持久化存储（**不做这步数据会随重启消失**）

- [ ] 挂 CFS 到 **`/data`**（镜像里 `/app/uploads` 已软链到 `/data/uploads`）
- [ ] 发布后验证：① `GET /api/health` 返回 200 且 `plugins.total > 0`；② 重启服务后数据还在；
      ③ `PRAGMA journal_mode` 应为 `delete`（不是 `wal`）、`PRAGMA integrity_check` 为 `ok`
- [ ] 首次启动用 `SUPERADMIN_*` 建超管，登录一次确认；再用超管预置**一个班 / 一个学生 / 一份作业**
      （审核员看到的就是这套数据）

### D5 小程序侧切到云托管

- [ ] `miniprogram/config/index.ts`：`TRANSPORT = 'container'`、填 `CLOUD_ENV`（环境 ID）、
      `CLOUD_SERVICE`（服务名）
- [ ] 清空 `DEV_LOGIN_OPENID`、确认 `MOCK.enabled === false`
- [ ] 真机验证一次 `callContainer`（工具里行为不完全等价）

## 附 1 · 一页速查（踩过的坑）

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `-601009 该小程序没有绑定手机号` | 账号资料缺手机号（第三方快速创建的常见） | 成员管理 → 管理员 → 修改 → 补手机号 |
| 名称提示要《商标注册证》/教育资质 | 名称含教育行业词（班级/课堂/…） | 换名，见 A3 |
| 「请先补充小程序基本信息」挡住备案/开发 | 名称/头像/简介/类目未填 | 先填 A3 + A4 |
| 云托管开不了环境 | 小程序未绑定手机号 / 未选中小程序 | A2；扫码登录时必须选**这个小程序** |
| 上传代码包失败 | 官方上限 **2 MiB**，本仓库 **86.86 MiB** | 用「绑定 GitHub 仓库」 |
| 发布按钮点不动 | 备案未完成 | 完成阶段 B |
| 手机能请求、真机不行 | 开发者工具的"不校验合法域名"只对本机有效 | 走云托管 `callContainer`（Track A 不需要域名白名单） |

## 附 2 · 红线（做了就出局）

1. **别点「账号注销」** —— 账号会没，要重新注册
2. **别把 AppSecret / 上传密钥 / ENCRYPTION_KEY 贴进聊天、issue、仓库**
3. **别买账号、别借他人身份**（包括同学、网友）
4. **别为了省钱不挂 CFS** —— 重启即丢库，等于作品没了
5. **别设最大副本 > 1** —— SQLite 两个写者 = 数据损坏
